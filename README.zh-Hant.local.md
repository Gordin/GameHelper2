# GameHelper2 繁體中文介面與新增插件

依原專案 README 建置完整 `GameOverlay.sln`，由輸出目錄執行 `Launcher.exe`。按 **F12 → 常規與快捷鍵 → 語言 → 繁體中文** 選擇介面語言。簡體與繁體共用插件設定及統計資料。字型需支援中文字形，並選擇完整中文字集。

## 漢化與介面

目前主程式與 11 個插件的 1,674 條英文基準介面資源皆有繁中與簡中版本，包含 Atlas2 資料表的 67 條祭祀詞綴及其短標籤。顯示翻譯保留 metadata、stat 編號、權重與已儲存的規則；未知名稱維持原文。這不是全遊戲所有裝備隨機詞綴的翻譯資料庫。

物品、地圖與預兆名稱參考 [PoE2DB 換界石](https://poe2db.tw/tw/Waystones)、[預兆](https://poe2db.tw/tw/Omen)、[通貨](https://poe2db.tw/tw/Currency) 的英文與繁中對照。遊戲讀出的名稱依客戶端語言顯示。

設定依「刷圖與收益、地圖與探索、角色與戰鬥、拾取與物品」分類，支援中文名、原名及描述搜尋。未啟用插件仍有入口，社群新插件可在「其他插件」找到。主視窗、搜尋、退出確認皆由 ImGui 繪製；原創生成底圖與提示詞見 `GameHelper/Assets/README.md`。

F12 → 地圖與探索 → 輿圖助手 → 輿圖設定，可勾選「隱藏普通地圖標識」。它隱藏普通節點的插件名稱與附加標識，保留特殊事件、傳奇地圖、已選分類和搜尋／導航目標，路線圖不受影響。預載入提示的附帶計時預設關閉；舊設定首次更新也會關閉，以後手動開啟的選擇會保留。關閉計時且沒有提示時，鎖定的空框不會顯示。

## 刷圖通貨統計

F12 → 刷圖與收益 → 刷圖通貨統計。橫向統計條顯示地圖數、平均時間／收益、總收益、每小時收益與會話時間；亦提供詳細視窗、暫停、歷史紀錄及 CSV 匯出。

只記錄有效採樣期間背包通貨總量的正向增加。堆疊拆分／合併不重複計數，資料中斷後重新建立基準，期間變化不補計。估值採用 LootValue 相同聯盟及來源的有效快取。未計裝備、金幣錢包與開圖成本。詳見 `Plugins/LootTracker/README.zh-Hant.md`。

## 傳送門互動恢復

F12 → 刷圖與收益 → 傳送門交互恢復。已接入目前客戶端 0x69/0x6A 兩個欄位的恢復邏輯，寫入前必須通過程式碼特徵、門身分及目前區域驗證；未知版本保持唯讀。原先導致崩潰的指標區域不會寫入。已完成離線測試及目前客戶端的唯讀匹配驗證，顯示及實際進圖效果等待使用者測試。詳見 Plugins/PortalAccess/README.zh-Hant.md。

## 驗證

可重現的資源校驗、統計／持久化測試、記憶體讀寫與還原測試、ImGui 互動與字型檢查見 `Tests/README.md`。離線預覽使用範例資料，不是遊戲內實拍；測試不會連接遊戲。
